# Guided onboarding
Start by asking whether the user is creating a new project or resuming one. Explain that integrations are per user, not bundled with the community skill. Ask one connection question at a time and confirm access before proceeding.

1. Project name, website URL, project type (shop or company site), language, target country and goals.
2. Storage: Google Drive + Sheets if available, another connected location, or local files. Never assume ownership or a fixed folder. Ask before creating project folders. Keep each brand/client isolated.
3. Ahrefs: whether available and connected; subscription level only if relevant. A subscription does not automatically imply API/MCP access.
4. DataForSEO: whether available, supported integration route and API spending limit. Never ask for secret keys in public files.
5. Search Console: choose property and verify authorized access; optionally via a tool that actually exposes its data. Do not claim that Ahrefs connection guarantees GSC data.
6. Google Keyword Planner: optional; verify account/API availability.
7. Reporting: test ability to create PDF and editable Google Sheet. If unavailable, generate portable CSV/XLSX and PDF locally where possible.
8. Undetectable AI: optional manual handover only. No automatic credit consumption.
9. Confirm setup summary, unavailable sources and fallback workflow; ask permission to start research.

Always distinguish connected, not connected, and unverified. Keep per-user configuration private and never commit credentials or customer research to a public repository.
