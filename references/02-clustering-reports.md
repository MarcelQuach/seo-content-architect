# Keyword clustering and reports
Cluster by search intent, SERP URL overlap, semantic topic, audience and stage of journey. Never cluster solely by word similarity. Map each cluster to one primary target URL/content type:
- Product detail: specific item/model, attributes, purchase intent.
- Category: broader assortment, comparison and shopping intent.
- Blog/editorial: informational questions, guides, comparisons and decision support.
- External guest contribution: genuinely relevant external audience, unique editorial topic, suitable destination and non-manipulative anchor suggestion.

For each cluster include ID, name, primary keyword, secondary keywords, intent, proposed content type, destination URL, evidence sources/dates, search metrics where available, SERP observations, rationale, cannibalization risk, priority and user decision/status.

Produce a reviewable PDF with cluster summary, methodology, evidence, mapping and unresolved questions. Produce an editable master spreadsheet / Google Sheet with tabs for raw keywords, clusters, URL mapping, editorial calendar, SERP evidence, decisions and change history. No automatic publication. Ask the user to approve or edit assignments before drafting.
