# SEO Content Architect — Community Edition v1.1

An evidence-first SEO skill for ecommerce shops and company websites: keyword research, fresh Google SERP analysis, intent-based clustering, editorial mapping, expert interviews, content creation and two-stage quality assurance.

**[Installation guide](INSTALLATION.md)** · **[Skill instructions](SKILL.md)**

## What it does
- Guided, per-user onboarding for Ahrefs, DataForSEO, Google Search Console, optional Google Keyword Planner, Google Drive and Sheets.
- Research-driven keyword clusters for **product descriptions, category pages, blog posts and external guest articles**, with user-controlled anchor-text suggestions.
- Human-reviewable **PDF clustering report** and editable **Google Sheet master**, where supported by connected tools.
- Fresh SERP evidence and an interview to capture genuine first-hand expertise before drafting.
- Mandatory QA A, optional **manual** Undetectable AI handover, then QA B comparing original and revised text.
- Individual brand/client workspaces; no hard-coded user accounts or project folders.

## Install
See **[INSTALLATION.md](INSTALLATION.md)** for platform-specific instructions. GitHub is the distribution source; installation depends on the target AI product and its supported Skills workflow.

## Important limitations
The skill does not include paid API subscriptions or automatic account access. It checks integrations and permissions before use. Live SERP, PDF and Sheets features require compatible tools. It cannot guarantee rankings or immunity from Google penalties. No secrets or client data should be committed to this public repository.
