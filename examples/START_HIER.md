# Erster Start

Nach Installation:

> Starte SEO Content Architect und führe mich Schritt für Schritt durch die Einrichtung meines eigenen Projekts. Prüfe die Anbindungen einzeln und beginne erst nach meiner Freigabe mit der Recherche.

Der Assistent fragt nach Projektart (Shop/Firmenwebsite), Markt, Sprache, Ablage, Ahrefs, DataForSEO, Search Console, optional Keyword Planner und menschlicher Freigabe des Research-Briefings. Das Skill-Paket enthält **keine** Kontoanbindung oder API-Schlüssel.

**Test der Hilfsskripte:**
```bash
pip install reportlab
python scripts/build_cluster_report.py examples/report_input.example.json cluster_demo.pdf
python scripts/compare_versions.py draft_a.txt draft_b.txt vergleich.html
```
Das Beispiel ist explizit als Demo markiert.
