# Editorial release checklist

## QA A — first draft
- [ ] User's expert contributions preserved and accurately attributed
- [ ] All concrete assertions checked against approved sources
- [ ] Search intent and content type match live SERP evidence
- [ ] Primary and supporting keywords used naturally
- [ ] No invented numbers, features, reviews, authorities or guarantees
- [ ] Correct internal links and appropriate outbound references
- [ ] Brand voice, readability and compliance checked
- [ ] User approval before any optional humanizer

## Optional manual Undetectable AI
- [ ] User intentionally chooses whether to spend credits
- [ ] Original approved draft stored for comparison
- [ ] No automated submissions

## QA B — if revised text exists
- [ ] Every material fact/claim unchanged or verified
- [ ] Expert insights and examples retained
- [ ] No erroneous wording, dropped specifications or harmful simplification
- [ ] Keyword strategy, links, headings, intent and tone preserved
- [ ] Final text explicitly approved
