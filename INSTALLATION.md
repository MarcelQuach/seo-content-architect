# Installation — SEO Content Architect Community Edition

## Claude (Skills support)
Download the repository as ZIP from GitHub (Code → Download ZIP). In the ZIP, locate the `seo-content-architect` skill directory with `SKILL.md` at its root. If your Claude interface supports custom Skills, upload the skill package following its current Skills installation flow. Availability varies by plan and interface.

## Claude Code
Clone the repository, then place its skill folder in the Skills directory supported by your installed Claude Code version. Preserve `SKILL.md` and the `references/` folder.

## Codex / compatible skill runners
Install or copy the repository as a skill folder using your tool's supported skills installation mechanism, ensuring `SKILL.md` is at the root. Different clients may require a particular skill directory or installer.

## ChatGPT
A GitHub repository is not automatically a one-click ChatGPT skill installation. Where the interface supports custom instructions, project files or workspace skills, use the `SKILL.md` and references according to the capabilities available in your account. GitHub access alone does not install an executable skill.

## First use
Ask: “Starte SEO Content Architect und führe mich Schritt für Schritt durch die Ersteinrichtung. Frage jede Anbindung einzeln ab und verwende ausschließlich meine eigenen Konten.”

Connections (Ahrefs, DataForSEO, Search Console, Keyword Planner, Google Drive/Sheets) are optional and must be authorized by each user. Do not put API keys in this public repository. Humanizer use is always optional and manual.
